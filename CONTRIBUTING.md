# Contributing

Bug reports and suggestions are welcome. Describe the version, expected and
observed behavior, and a reproduction using fictional data. Report security
issues privately as described in [SECURITY.md](SECURITY.md).

Outside code/documentation contributions are not being accepted yet. Claypond
is preparing contributor terms; this repository does not treat an issue,
fork or pull request as consent to a separate commercial licence. The policy
will be updated when those terms are adopted.

For local development, follow [running](docs/running.md). Keep a logical change
small enough to review. Use the existing MUI dark theme, preserve organization
and role boundaries, and exercise the actual behavior changed. Run `bin/check`
before proposing a change. Do not weaken a check to get a passing result.

Code is AGPL-3.0-only; documentation is CC BY-SA 4.0. Existing dependency notices
and trademark rights remain separate. [Development details](docs/contributing.md)
cover the source layout and checks.
