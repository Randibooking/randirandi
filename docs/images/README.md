# Illustrations and product views

The fourteen community-house illustrations are original RandiRandi artwork.
The SVGs are editable sources; the PNGs are their browser-rendered exports.
They explain booking behavior using fictional places, dates and prices.
They do not depict an application floor-plan feature or default configuration.

The drawings reuse RandiRandi’s existing palette and Inter typography. Embedded
Inter fonts retain their SIL Open Font License notices inside the SVGs. The
portrait retains the provenance recorded in `frontend/brand/asset-sources.json`.
Artwork is AGPL-3.0-only; the RandiRandi name and logo retain their separate
trademark protection. See [Trademarks](../../TRADEMARKS.md).

Product captures show the actual English application with the fictional
HarbourView setup. Members, orders and dates are demonstration data. A local
free booking exercises the calendar, cart, confirmation and booking history;
it does not demonstrate Vipps or email delivery. Local sessions were seeded
for the capture, so the walkthrough does not test sign-in or administrator MFA.

See [the illustrated guide](../illustrated-guide.md) for the explanations.
